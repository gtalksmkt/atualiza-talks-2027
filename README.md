# Atualiza Talks ME 2027

Landing page do **Atualiza Talks ME 2027**, programa de atualização continuada em Medicina de Emergência da Emergency Talks para médicos com ou sem título de especialista. A logo leva a sigla "me" (Medicina de Emergência) em vermelho ao lado de "talks".

- `index.html` — landing (página única, estilo streaming)
- `logo-propostas.html` — propostas de logo e paleta
- `logo/` — ícone e símbolo em SVG

Publicada via GitHub Pages (branch `main`, raiz). Página marcada com `noindex` enquanto preço, docentes e regras do certificado estão pendentes.
