Para quem é este curso?

O Atualiza Talks é para médicos que já têm título de especialista em Medicina de Emergência. Selecione a opção que descreve você:

Clique em uma das opções

Este curso foi feito para você.

Depois do título, o desafio é se manter atualizado. O Atualiza Talks organiza essa rotina para você: artigos relevantes comentados toda semana e um encontro ao vivo por mês para discutir evidências e a prática na emergência, com profundidade técnica e linguagem clara.

  • 12 meses de atualização, de janeiro a dezembro de 2027
  • Conteúdo novo toda segunda-feira
  • Um encontro ao vivo por mês, com gravação no portal
Ver o que está incluído

Para você, o curso certo é outro.

O Atualiza Talks não é um preparatório para a prova de título nem para o RQE: ele é para quem já é titulado. Se você vai prestar a prova, conheça o TEME 2027, o preparatório da Emergency Talks. Depois de conquistar o título, o Atualiza Talks continua com você.
